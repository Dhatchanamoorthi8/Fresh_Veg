🏗️ 5-Tier Layered Architecture
Presentation
State Management
Repositories
Supabase BaaS
Tier 1: Multi-Platform Presentation & Apps
Flutter Monorepo Client Applications
🛒 vegora_customer / Hub
Customer app: Branch selector, Category browsing, Instant Cart, Order Tracker
🏬 Branch Staff Portal
In-store staging: Accept orders, bag veggies, weight check, handoff packaging
🛵 vegora_delivery Agent
Delivery partner portal: Trip acceptance, transit route, doorstep confirmation
⚙️ vegora_admin_web Hub
Admin dashboard: Multi-branch inventory, price manager, agent assignment, reports
Tier 2: Navigation & Reactive State Orchestration
GoRouter RBAC Guards & Riverpod 3.x Providers
🚦 GoRouter + AuthListenable
Dynamic role guards: customer, branchStaff, deliveryStaff, branchAdmin, superAdmin
🧺 CartProvider & OrderProvider
Async state management for subtotal, delivery charges, item quantities
📍 BranchProvider
Geofenced branch context, active stock cache, local pricing multipliers
🔐 AuthProvider
Supabase auth session tracking, role claims validation, JWT persistence
Tier 3: Domain Entities & Repository Contracts
Shared Packages (vegora_models & vegora_repositories)
📦 SupabaseOrderRepository
Place orders, fetch branch queues, advance status (NEW → DELIVERED)
🥬 SupabaseCatalogRepository
Produce catalog, pricing variations, categories, promotions & discounts
🏬 SupabaseBranchRepository
Branch coordinates, operating hours, delivery radius, staff roster
🛡️ SupabaseAuthRepository
Sign In/Up, Google OAuth, password recovery, profile metadata
Tier 4: Cloud Backend Infrastructure
Supabase Backend as a Service (PostgreSQL & Realtime)
🗄️ PostgreSQL Database
18+ tables: orders, order_items, branch_inventory, delivery_assignments, user_roles
🔒 Row Level Security (RLS)
Granular row policies: Customers see own orders; Staff sees branch orders; Admins manage all
⚡ Supabase Realtime (CDC)
Postgres WebSocket broadcast on orders table; instant push to Customer & Driver apps
🖼️ Supabase Storage
Buckets: product-images, categories, customer delivery photo proofs
